# L4 生产基建 Sprint 0 实施清单

> 本清单直接执行，不增加新的产品确认关卡。真实 Feishu、CB、菁优网与业务题库仍保持只读/未连接。

## 目标

把一期“可演示状态机”补强为可以安全承接小规模真实试产的底座：输入可冻结、写入不丢失、任务可恢复、规则回测不泄漏未来数据。

## 验收标准

1. 多线程请求不会发生 JSON 状态丢写；每次提交增加状态修订号并保留可恢复备份。
2. 旧版状态可以自动迁移到当前 schema，不直接改坏现有本地演示数据。
3. 本地文件、本地文件夹、Feishu Base 配置和 CB 导出配置都可生成不可变来源快照；本地文件记录哈希、大小和相对路径。
4. 输入快照只保存允许的教学资料格式，限制单文件/总大小，禁止跟随符号链接导出目录外内容。
5. 每个阶段生成幂等任务记录，保存执行器、输入快照、规则版本、尝试次数、输出摘要与失败原因；相同幂等键不会重复执行。
6. 冻结预测明确训练年份、验证年份、数据截止时间、规则版本、样本口径和预测对象；验证年份不得早于或混入训练年份。
7. 回测结果真实计算 TP/FP/FN、precision、recall、分子分母和误判/漏判清单；没有观察数据时不生成虚假提升。
8. API、界面和 README 能查看输入快照、任务健康和回测结果；所有自动化测试通过。

## 实施任务

### Task 1：事务存储与 schema 迁移

- 修改 `apps/l4_workbench/store.py`：线程锁、文件锁、事务 API、修订号、备份与恢复。
- 修改 `apps/l4_workbench/domain.py`：schema v2 数据契约与兼容迁移。
- 重构 `apps/l4_workbench/service.py`：所有写操作必须在同一事务内完成。
- 测试并发更新、备份生成、旧状态迁移和指定修订恢复。

### Task 2：来源冻结快照

- 新建 `apps/l4_workbench/pipeline.py`。
- 支持 `local_files`、`local_folder`、`feishu_base`、`cb_export` 四种来源描述。
- 本地来源复制到 `outputs/l4_workbench/source_snapshots/<snapshot_id>/raw/`，生成 SHA-256 清单。
- 远程来源只记录连接契约和待适配状态，不抓取、不上传、不写外部系统。
- 新增来源快照 API 和数据页。

### Task 3：幂等可恢复任务

- 新建 `apps/l4_workbench/jobs.py`。
- 为每个阶段记录 job、幂等键、attempt、输入/规则版本、开始/结束时间和输出。
- 一期仍使用本地同步执行器，但接口明确区分 `dry_run` 与 `production`，不得把占位结果标成真实生产成品。
- 测试重复运行复用、失败记录和恢复。

### Task 4：冻结预测与真实回测

- 新建 `apps/l4_workbench/backtest.py`。
- 实现预测冻结校验、内容哈希和不可变记录。
- 实现后验观察集评估，输出 precision/recall、分子分母、误判和漏判。
- 新增回测 API 和规则实验室展示。

### Task 5：回归与交付

- 更新样例状态、README 和演示脚本。
- 运行 `unittest`、`py_compile`、JavaScript 语法检查和浏览器主路径验证。
- 保持原押题宣传审计工具可启动。
