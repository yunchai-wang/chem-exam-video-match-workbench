# L4 课程自进化平台：完整功能路线与工期评估

## 1. 估算口径

- 这是从当前代码状态继续开发的**剩余工期**，不是从零重做。
- 单位为“人日”，按 1 名熟悉现有代码和业务的工程师每天约 6 小时有效开发计算，范围已包含自测、联调和缺陷修正，不包含节假日。
- “比赛 MVP”只要求一条真实闭环和可核验效果；“内部可用”要求老师能稳定试产；“正式生产”还包含权限、安全、监控、容量、恢复和跨学科回归。
- 教研规则确认、真实数据授权、PMO/CB 接口协调、菁优网官方 API 等待时间单列，不能靠加速写代码消除。
- 当前范围很大，单项估算误差约 ±30%；每完成一个里程碑重新校准一次。

## 5. 推荐的比赛范围与日历工期

### 5.1 推荐范围

比赛主线只做一条：

> 初中化学真题/Base → 标准化 → 高频/好题/趋势 → 保守视频缺口与证据 → 候选题/小问确认 → 教案 → 逐字稿 → 分镜 → PPT 交接或 HTML（二选一主展示）→ 教师最终成品反馈 → 规则归因 → 历年回测与可视化。

备考试题池可以作为同一数据底座上的第二个出口展示；菁优网正式 API、学生数据、CB 自动写入、全学科生产和全部自定义产物不应成为参赛主链路的上线前置条件。

### 5.2 日历估算

| 团队配置 | 比赛 MVP | 3～5 位老师内部试产 | 全部功能生产化 |
|---|---:|---:|---:|
| 1 名全职工程师 | 16～22 周 | 28～40 周 | 56～80 周 + 外部等待 |
| 2 名互补工程师 | 10～14 周 | 18～26 周 | 36～52 周 + 外部等待 |
| 3 人小组（数据/全栈、AI教研、集成测试） | 7～10 周 | 13～20 周 | 26～38 周 + 外部等待 |

这里的“3 人小组”不是 3 名教研兼职写代码：至少需要 1 名稳定负责工程底座和 1 名负责数据/模型评测；教研负责人提供金标准、边界审核和每周固定验收即可。

## 6. 建议的 10 周比赛节奏（3 人并行）

1. 第 1～2 周：完成 F01～F04，拿真实 Word/PDF/Base 做 100～300 题金标准抽检。
2. 第 3～4 周：完成 F06～F09，交付保守覆盖证据、独立高频/好题字段和优先级。
3. 第 5 周：完成 F10/F11，跑通候选、小问、批量通过和母题边界。
4. 第 6～7 周：完成 F12/F13/F14，接真实教案/逐字稿 Skills 和最终成品后验反馈。
5. 第 8 周：选择 F16 或 F17 作为主产出，另一条只做轻量演示。
6. 第 9 周：完成 F18 与 F19 的最小版，展示历年预测—验证—规则变化和地区备考池。
7. 第 10 周：跨学科小样本回归、失败案例、性能/恢复演练、答辩脚本与录屏。

## 7. 工期中的高风险项

1. **题目图片物化与版面还原**：附件权限、PDF 扫描质量、跨页题、公式与图表关系会直接影响教案可靠性。
2. **视频覆盖金标准**：没有 100～300 条教研标注样本，就无法证明保守匹配质量，而只能展示规则。
3. **趋势回测口径**：必须按时间冻结规则和预测，不能用 2026 年知识回头“预测”2024 年。
4. **外部系统写入**：PMO、CB、云文档和兼职触达都需要权限、字段契约、幂等键和撤销策略。
5. **教师反馈稀疏**：平台可自动运行，但公共规则/公共 Skill 发布仍必须人工批准，项目内自动实验不能污染其他老师。

## 8. 下一开发包

当前最合适的下一个包是：

1. 从已经本地冻结的真实题目资产中选取 30～50 道，建立含正常题图、共享材料图、跨页图和异常长图的标准化金样本；
2. 在金样本上接入“高频/好题/趋势/保守视频覆盖/生产优先级”的真实规则执行器；
3. 增加字段映射模板保存、交叉筛选和 Word/PDF 可编辑下载；
4. 仅对本地缺图的来源补 Base 分页全量读取与附件物化，避免重复搬运已有题图。

完成这四项后，平台才从“资料能进来”进入“能真实给出教研诊断”的阶段。
