# L4 真题驱动的课程自进化平台一期演示脚本

## 演示目标

用一条真实可操作的纵向闭环说明：平台不是“AI 连续生成几份文档”，而是让题目资产、教师判断、生产结果和后验数据持续回写规则，使下一轮生产更准确、教师介入越来越少。

## 启动

```bash
python3 apps/l4_course_evolution_workbench.py --port 8766
```

打开 `http://127.0.0.1:8766`。

## 路径 A：按节点介入

1. 在“项目驾驶舱”说明当前服务对象、地区、考试类型、年份和计划产物；强调这些字段影响当前任务优先级，但不会把差题改判成好题。
2. 点击“开始 AI 运行”。脱敏样例中的“解析冲突题”触发资料标准化异常复核；正常题不需要重复检查。
3. 点击“通过本节点并继续”。下一步因为该题没有视频逐字稿/截图证据，诊断节点显示“无法判断”，老师可以后续补证据或给出人工结论。
4. 再次放行后，运行停在项目预设的“好题候选与生产优先级每次确认”。指出高频、好题和优先级是并列判断：高频基础题仍可能只是 P3。
5. 放行后，母题、教案、逐字稿、分镜与成品自动完成。

## 路径 B：完全自动＋成品后验反馈

1. 点击顶部“切换为完全自动”，再启动一轮运行。AI 不等待老师逐节点审核，直接生成成品。
2. 进入“成品与后验反馈”，输入：`逐字稿不够口语，第二段过渡太硬。`
3. 提交后观察：成品升级为 V2；系统将根因归入逐字稿，不重复运行资料标准化、选题、母题和教案，只重跑逐字稿及分镜。
4. 进入“规则进化实验室”，查看由反馈生成的项目隔离实验规则。脱敏样例没有真实保留集，因此实验指标明确显示“待回测”，不捏造提升数据；接入冻结的 23～26 年真题后再计算真实 A/B 结果。
5. 点击“申请发布为公共规则”，结果只会是“待人工批准”。说明局部样本可以驱动项目内自进化，但不能自动污染所有老师的公共生产系统。

## 题目资产讲解点

- 高频显示分子/分母、去重口径和理由，不只显示“高/中/低”。
- 好题展示结构完整、典型性、诊断性和迁移性等维度，且保留 AI 与教研结论。
- 视频生产覆盖使用保守口径，并显示证据层级；多个视频讲过局部知识，只能判“组合支撑”，不能直接当作完整覆盖。
- P0 不属于生产优先级。内容错误进入独立纠错队列；通过内容健康检查后才排 P1～P3。
- 原题中的图、表、装置和坐标图必须随题保留。一期以“原题图表保留区”外显该数据契约，接入真实题库时替换为真实题图。

## 一期与下一阶段的边界

一期已经验证领域模型、状态机、反馈归因、规则治理、API 和本地交互；仍使用脱敏样例。下一阶段接入：

1. 多来源资料导入与字段映射；
2. 每位老师的闭环 Feishu Base；
3. Word/飞书文档/题目包导出；
4. 视频逐字稿与截图证据索引；
5. PMO、PPT/HTML 路由和兼职触达；
6. 跨年度回测数据与可交互趋势仪表盘。
