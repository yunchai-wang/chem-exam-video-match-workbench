# Codex 接力包使用说明

本目录用于在不同老师、不同 Codex 任务之间交接平台开发。它只记录代码状态、规则版本、脱敏统计和续作说明；真实试卷、题图、逐字稿、视频截图、账号凭据与本地运行状态不得提交到 GitHub。

## 什么时候刷新

- 每完成一个测试全绿、可独立验收的小里程碑；
- 用户说“生成接力包”时，立即停止扩展范围，先完成测试、提交代码并更新 `CURRENT.md`；
- 当前 Codex 额度即将不足或需要换人时。

## 发送给接力人的最小内容

1. GitHub 仓库地址；
2. 分支名；
3. `docs/handoff/CURRENT.md`；
4. 如需复现真实数据，再通过公司批准的私密渠道提供数据位置或让对方使用自己的闭环 Base，不能把真实数据提交到仓库。

## 接力纪律

- 先读取 `CURRENT.md`，再查看代码；不要从聊天记录猜项目状态。
- 先运行其中的验收命令，确认基线全绿后再改代码。
- 一次只推进“下一优先事项”，通过测试和界面验收后再扩展。
- 保留生产口径与宣传口径的隔离，不把宣传命中结论写回生产覆盖字段。
- 完成后更新 `CURRENT.md`，写清新提交、真实完成项、剩余风险和下一步提示词。
