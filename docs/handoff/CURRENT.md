3. 自动生成 30/40/50 题待校准金样本，覆盖试卷、题型、难度、图表形态和异常样本。
4. 可选边界校准台：原题图、AI 高频/好题、视频候选、科学性和覆盖结论并排；单题纠正需写理由，批量通过不覆盖既有纠正且不吞掉异常；无教师反馈不阻塞 AI。
5. 校准反馈自动归因到当前项目隔离规则族，不自动发布为跨项目公共规则或公共 Skill。

8. 旧清单曾用飞书行号作为视频 ID；目录插行后会把逐字稿证据错挂到其他视频。新合并脚本按“课库＋规范化视频名”继承证据，行号只有标题仍一致时才能兜底。
9. `production-coverage-v0.3` 同时检索三类课库，仍要求底层结构、语义锚点、设问任务和强逐字稿证据。40 题金样本重跑结果仍为 22 题部分覆盖候选、15 题证据不足、3 题无法判断；目录扩容没有虚增命中。

## 下一优先事项

把当前金样本诊断推进为真实“好题候选池与生产优先级”闭环：

1. 由真实诊断结果生成题目单元级候选池；高频与好题继续保持两个可同时命中的独立字段。
2. 将视频覆盖、考试趋势/频次、目标学生预计收益、迁移价值、跨地区复用、现有资产可替代性和制作成本分别外显；缺学生数据时只给“教研预测”，不伪装为实证。
3. 简单基础题默认进入 P3 题库保留；只有高频易错、关键前置台阶或有学生数据支持时，才建议 P2/P1。
4. 教师可按整题、小问或选项确认进入生产，支持“好题但不生产”“非好题但可改造成母题”等分流；任何纠正理由进入隔离规则实验。
5. 视频证据页补齐逐字稿命中片段、关键截图和时间码；7 个待核同名簇提供合并/拆分入口，但这不应阻塞候选池生成。

验收标准：候选池来源可追溯到真实题目资产和规则版本；频次、好题、覆盖、优先级字段互不覆盖；无学生数据不生成伪实证；教师可选介入且无反馈不阻塞；桌面/移动端无溢出；全量测试通过。
