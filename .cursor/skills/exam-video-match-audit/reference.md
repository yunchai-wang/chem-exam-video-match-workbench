# 参考：门禁、输入清单、迁移

## 三像门禁

| 维度 | 通过标准 |
|------|----------|
| 题图像 | 表格/曲线/装置/流程版式同类 |
| 任务像 | 设问任务一致（对照、滤液成分、读溶解度、产率极值…） |
| 解法像 | 学生动作一致（找对照组、读曲线、流程推断…） |

## 曲线类型门禁

| 类型 | 卷面特征 | 宜配 | 禁止误配 |
|------|----------|------|----------|
| 产率/条件 | 纵轴产率%，问适宜条件 | XZK-21、ZND-27 | ZND-24、溶解度专课 |
| 溶解度 | g/100g 水，饱和/结晶 | XZK-27、JCTB-145/146/150 | XZK-46 |
| 滴定 pH | 中和滴定、数字化 pH | JCTB-158、XZK-14 | 泛流程课 |
| 科普折线 | 材料内实验数据 | XZK-21、ZND-27 | 工业流程课 |
| 双线对比结论 | 两线+开放写证据 | XZK-21（下） | XZK-20（上）、XZK-14 |
| 科普·材料性能读图 | 新型材料/配方性能 + 坐标图/表解释 | **XZK-20（上）** | 只写「信息提取」不配素材域；工业流程课 |

## 科普阅读两阶段（形式入围 + 同构前置）

| 阶段 | 规则 | 示例 |
|------|------|------|
| **入围** | 形式相似即可 | 信息提取 + 曲线图 / 数据表 / 控制变量分析 |
| **排序** | 素材主题 **或** 数据作答与课内例题同构 → 截图 **前置** | 遂宁 Q16：`XZK-20` 前置；`XZK-21`/`ZND-27` 形式补证靠后 |

引擎字段：`popsci_form`（形式标签）、`isomorph_rank`（0=仅形式，2=单轴同构，3=双轴同构）。

**XZK-20（上）** vs **XZK-21（下）**：前者易同构「材料性能+读坐标图」；后者易同构「双线写证据/产率极值」。详见 SOP §5g。

## PDF 题图跨页裁切

引擎：`scripts/visual_v5_2026_yt.py` 内 `crop_question()`。

| 场景 | 处理 |
|------|------|
| 最后一题无下一题号 | 向后扫描续页：含 `(2)(3)`、`图1/图2`、任务二、多图 |
| 参考答案在页首 | **不裁**该页（避免「参考答案与试题解析」条带进宣传版） |
| 页脚 | 按「第 N 页（共 M 页）」截断，减少页脚拼进中间段 |

自检：

```bash
.venv/bin/python scripts/visual_v5_2026_yt.py --prepare   # 重生成 pdf_question_crops
.venv/bin/python .cursor/skills/exam-video-match-audit/scripts/crop_scan.py
```

| crop_scan 规则 | 含义 |
|----------------|------|
| `CROSS_PAGE_MAYBE` | 题干含如图/后续小问，但 `pdf_page` 只有单页 |
| `CROP_TALL_CHECK` | 跨多页且裁图过高，复核末段是否含答案条 |

标杆：**凉山 Q16** — 任务一在 p6 末，图1/图2 与 (2)(3) 在 p7；正确 `pdf_page=6-7`，勿含 p8 答案区。

| ID | 课名 | 勿用于 |
|----|------|--------|
| XZK-9 | 成分探究·干扰物质 | 滤液/金属回收（除非 NaOH-CO₂ 干扰情境） |
| XZK-46 | 树状图·金属回收 | 溶解度/晒盐/产率读图 |
| ZND-24 | 流程·沉淀 pH 范围 | 产率-温度/pH 实验曲线 |
| XZK-22 | 工艺流程审题 | 单独替代滤液专课或溶解度专课 |

写 `allowed_video_ids` 前在 `video_records_v5.json` 核对 `video_name`。

## 双层匹配标准

| 层级 | override 字段 | 通过标准 |
|------|---------------|----------|
| 宣传版 | `promotion: allow` | 题型大类对大类；三像；选择题慎重 |
| 对比表 | `comparison_show` + `comparison_video_ids` | 锚重点小问；任务+解法同构；不计宣传版分值 |

## 解法相似（扬州/苏州）

解法像 = **条件表现** + **设问句式** + **学生动作**。

| 子模式 | 卷面特征 | 宜配 |
|--------|----------|------|
| 同物质异状态·双曲线+依据 | 同物质两种粒径/状态，双曲线，结论+判断依据 | **ZND-9** |
| 问实验①/对照目的 | 「设计实验①的目的是___」 | **XZK-38**（下） |
| 选方案多因素说理 | 可行+多方面理由 | **XZK-18** 供氧器2 |
| 利弊/成本评析 | 「从利弊两方面评析」 | 跨学科成本权衡课 |
| 项目块·导电性灯泡 | 石墨棒/灯泡亮灭 | **XZK-38**（下），非 XZK-36（上） |

## override 字段说明

| 字段 | 说明 |
|------|------|
| `primary_type` | 8 大题型之一 |
| `problem_tags` | 问题标签，复合题须覆盖所有得分维度 |
| `visual_forms` | 题图形态：流程图、曲线图、装置图… |
| `promotion` | `allow`（宣传版）或 `exclude` |
| `allowed_video_ids` | 宣传版白名单；allow 时必填 |
| `comparison_show` | `true` 时进对比表但不计宣传版命中 |
| `comparison_video_ids` | 对比表展示层视频 ID 列表 |
| `compare_table_show` | `false` 时宣传版命中但对比表不占行 |
| `compare_table_video_ids` | 对比表只展示白名单子集（分析表仍可列多课） |
| `task_video_map` | 项目式/跨学科按小问拆课 `[{anchor, video_ids, note}]` |
| `video_similarity_notes` | `{video_id: "口语相似点"}`，写入对比表右列 |
| `feishu_manual_compare` | 卷级：true 则 republish 跳过该卷（右列已定稿） |
| `feishu_manual_right` | 题级标记（文档用；与卷级配合） |
| `audit_note` | 审计理由；复合题写小问与对应视频 |

## 迁移到新批次/学科

| 改动项 | 说明 |

| PDF 目录 | `scripts/visual_v5_2026_yt.py` 内 `PAPER_DIR` |

引擎尚未完全实现规则文档「问题标签 70% 权重」——宣传版质量依赖人工白名单。

## 已知限制

- 部分截图来自教案 X 列（无 App 水印）——素材规范与匹配逻辑分开
- 过程库弱相关候选刻意保留，勿与宣传版混淆
- **`--republish-paper` 为整篇 overwrite**：左列题图与右列视频截图一并由引擎重写，会抹掉飞书手改右列。仅修左列时勿整卷 republish（见 SKILL「只改左列」）
